⚡ Multi-Protocol Engine

An ultra-fast, multi-protocol download manager focused on speed and simplicity.

Shusha pairs the raw multi-connection power of aria2 with modern WebSocket push events, real-time BitTorrent piece mapping, browser extension integration, and intelligent mirror probing.

Supports Linux, macOS & Windows Python 3.10+

Engineered for Maximum Throughput

1

WebSocket Real-Time RPC

Replaces high-overhead HTTP polling with persistent bidirectional WebSocket subscriptions (aria2.onDownloadComplete, onDownloadError).

2

BitTorrent & Tracker Aggregator

Automatic synchronization with public tracker lists (ngosang tracker lists), piece bitfield visualization, file priority toggles, and integrated .torrent/magnet generator.

3

Browser Extension Webhook Bridge

Embedded daemon HTTP server (localhost:6810) receives 1-click downloads from Chrome, Firefox, and Edge with full Referer and Cookie preservation.

4

Checksums & Mirror Prober

Automated multi-mirror latency probing (TTFB & byte range testing) paired with cryptographic verification for MD5, SHA-1, SHA-256, SHA-512, and CRC32.

Interactive Download Engine Simulator

Test Shusha's multi-chunk concurrency and piece allocation engine right in your browser.
