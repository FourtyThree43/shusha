Engineering Highlights

Built for power users, developers, and media archivers.

⚡

WebSocket Push Engine

Zero-delay asynchronous notification bus. State changes, completion events, and speed telemetry stream in real time over JSON-RPC 2.0 without polling lag.

🧩

Visual Piece Map

Bitfield chunk matrix displays piece-by-piece verified download progress. Inspect individual chunks, verification state, and piece hashes in real time.

🌐

Public Tracker Aggregator

Auto-syncs with daily updated public BitTorrent tracker lists (inspired by Motrix), maximizing peer discovery and download acceleration on magnet links.

🔢

Smart Pattern Sequences

Enter range patterns like http://site.com/ep[01-24].mp4 to instantly batch-add series, archives, or split segments with clipboard monitoring.

⏱️

Bandwidth Scheduler

Configure automated time-window throttling profiles (e.g. daytime limits for work hours, unlimited bandwidth overnight) with zero manual intervention.

🖥️

Cross-Platform Modern UI

Crisp High-DPI vector SVG icons and native system tray integrations across Linux (Wayland/X11), macOS (Retina), and Windows 10/11.
