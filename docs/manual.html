User Manual & Guide

Shusha is a modern multi-protocol download manager wrapping aria2c. It gives you raw 16-connection HTTP/HTTPS/FTP segmentation, BitTorrent peer aggregation, Metalink mirror balancing, and real-time WebSocket push updates.

# Install with uv (recommended)
$ uv tool install shusha
# Launch GUI or CLI directly
$ shusha --gui
$ shusha add https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.9.0-amd64-netinst.iso

2. Headless CLI Reference

Manage downloads, daemon lifecycle, and diagnostic tools directly from your terminal or shell scripts.

shusha add <URL> [--out <name>] [--split <n>] [--dir <path>]

Submits a new download URL, Magnet URI, or path to a local .torrent file.

shusha list [--status active|waiting|stopped|all]

Lists all queue items with GID, progress, size, transfer speed, and status.

shusha pause <GID|all> / shusha resume <GID|all> / shusha remove <GID> [-f]

Controls queue playback. Passing -f to remove deletes incomplete disk files.

shusha daemon [start|stop|restart|status]

Controls the background aria2c --enable-rpc daemon process.

shusha torrent create <source> [--output <file.torrent>] [--piece-size <bytes>]

Creates standard .torrent metadata and outputs a magnet:?xt=urn:btih:... URI.

shusha hash <file> [--algo md5|sha1|sha256|sha512|crc32|all]

Calculates cryptographic file hashes directly in the console.

shusha probe <URL1> [<URL2>...]

Benchmarks latency (TTFB) and HTTP range support across download mirrors.

3. BitTorrent & Tracker Management

Shusha includes a built-in tracker scraper syncing with updated public tracker repositories. In the Settings → BitTorrent & Trackers tab, you can enable auto-sync, adjust max peers per torrent (100+), enable DHT/PEX, and configure seed ratio limits.

4. Browser WebExtension Integration

The bundled Manifest V3 browser extension allows 1-click download handoff from Chrome, Firefox, Edge, and Brave directly to Shusha.

1. Open chrome://extensions or about:debugging in Firefox.
2. Enable "Developer mode".
3. Click "Load unpacked" and select the extensions/ directory in the Shusha repo.
4. Right-click any link or video and select "Download with Shusha"!
