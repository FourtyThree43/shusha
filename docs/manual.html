Shusha User Manual

Everything you need to know to get the most out of Shusha on Linux, macOS, and Windows.

1. Installation & Requirements

Shusha requires Python 3.10+ and aria2c installed on your system.

# Ubuntu / Debian
sudo apt install aria2 python3-tk
pip install shusha
# Arch Linux
sudo pacman -S aria2 tk
pip install shusha
# macOS (Homebrew)
brew install aria2 python-tk
pip install shusha

2. Batch Pattern Sequences

Click Batch on the toolbar to add multiple files at once. You can use numeric range brackets like [01-20] or alphabetic ranges like [a-z]:

https://example.com/archive_vol[01-08].part
https://cdn.photos.org/gallery/img_[a-d].jpg

3. Task Inspector & Piece Map

Double click any download or select it and click Details to open the full Inspector Window. Here you can monitor live transfer speeds, inspect individual BitTorrent pieces on the canvas grid, review connected peer IPs, and tweak speed limits.
