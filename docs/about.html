About Shusha

Shusha (Swahili for "to bring down / download") is an open-source, high-performance desktop download manager built on top of the world-class aria2 multi-source multi-protocol engine.

Core Principles

1. Zero Bloat: Uses standard library sockets and pure-Python modules wherever possible to keep execution instantaneous and resource-efficient.

2. Vector Crisp: Modern SVG rendering ensures all widgets and status indicators scale perfectly on 4K High-DPI screens without pixelation.

3. Reliability & Privacy: Runs 100% locally with zero analytics, zero telemetry tracking, and complete user privacy.
