API & RPC Reference

Complete guide for interacting with ShushaAPI, WebSocket events, and aria2 JSON-RPC methods.

ShushaAPI.add_uris(uris, options=None)

Adds one or more HTTP/HTTPS/FTP or Magnet URIs to the download queue.

from shusha.controller.api import ShushaAPI

api = ShushaAPI()
download = api.add_uris(
    ["https://releases.ubuntu.com/24.04/ubuntu-24.04-desktop-amd64.iso"],
    options={"dir": "/home/user/Downloads", "split": "16", "max-connection-per-server": "16"}
)
print("Added Download GID:", download.gid)

ShushaAPI.add_batch_urls(text_or_urls, options=None)

Parses multi-line text with pattern sequence expansion brackets (e.g. [01-10]) and dispatches downloads.

batch_text = """
http://example.com/assets/archive_part[01-05].rar
magnet:?xt=urn:btih:3b245504d603a1a6b0805342c3cd3ef10f9b6e23
"""
downloads = api.add_batch_urls(batch_text)
print(f"Dispatched {len(downloads)} tasks!")

ShushaAPI.on_event(event_name, callback)

Registers a real-time event listener for asynchronous daemon notifications.

def handle_completion(event_name, data):
    print("Download completed! GID:", data.get("gid"))

api.connect_ws()
api.on_event("aria2.onDownloadComplete", handle_completion)

Supported Real-Time Notification Frames

aria2.onDownloadStart Dispatched when a download begins executing.
aria2.onDownloadPause Dispatched when a download is paused.
aria2.onDownloadStop Dispatched when a download is aborted or removed.
aria2.onDownloadComplete Dispatched when HTTP/FTP download finishes and passes hash checks.
aria2.onBtDownloadComplete Dispatched when BitTorrent payload completes downloading.
aria2.onDownloadError Dispatched when a task encounters an unrecoverable network or disk error.

JSON-RPC 2.0 Frame Structure

{
  "jsonrpc": "2.0",
  "id": "req_101",
  "method": "aria2.addUri",
  "params": [
    "token:my_secret_token",
    ["https://example.com/file.zip"],
    {"dir": "/downloads", "split": "8"}
  ]
}
