API Reference & Specifications

Shusha interacts with aria2 via standard JSON-RPC 2.0 over HTTP (http://127.0.0.1:6800/jsonrpc) and persistent WebSockets (ws://127.0.0.1:6800/jsonrpc). Additionally, Shusha hosts a local HTTP Webhook Server on port 6810 for lightweight browser integration.

2. Core JSON-RPC 2.0 Methods

aria2.addUri

Adds a new download from one or more mirror URIs.

// Request Payload
{
  "jsonrpc": "2.0",
  "id": "req-1",
  "method": "aria2.addUri",
  "params": [
    ["https://example.com/file.zip"],
    { "dir": "/home/user/Downloads", "split": "8", "out": "archive.zip" }
  ]
}

aria2.tellActive

Returns the list of currently active downloads with transfer metrics.

// Request
{ "jsonrpc": "2.0", "id": "req-2", "method": "aria2.tellActive", "params": [["gid", "status", "totalLength", "completedLength", "downloadSpeed"]] }

3. Local HTTP Webhook Bridge (127.0.0.1:6810)

POST /add

Accepts JSON payload from extensions and scripts to queue downloads immediately.

curl -X POST http://127.0.0.1:6810/add \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/movie.mp4", "filename": "movie.mp4"}'
