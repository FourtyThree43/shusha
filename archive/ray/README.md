# Archive: Ray Prototype & Custom Widgets

This directory contains prototype implementations and experimental custom Tkinter widgets created during the early prototyping stage.

---

## Directory Structure

- **`src/gui/`**: Early UI mockup incorporating Tkinter canvas drawings, customized entry fields, and prototype button bars.
- **`src/gui/assets/`**: Historical button and indicator icons used by the prototype GUI.
- **`src/sandbox/`**: Experimental scripts evaluating table pagination and custom Canvas-based styling.

---

> [!NOTE]
> These prototypes were superseded by the modern `ttkbootstrap` + MVC architecture implemented under `src/shusha/`.
