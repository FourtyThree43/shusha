# Shusha Archive

This directory contains legacy experimental scripts, early GUI sandboxes, and development prototypes preserved for historical reference.

## Contents

- **`drafts/`**: Early UI iterations, Tkinter window experiments, and exploratory scripts originally located in `src/shusha/_drafts/`.
- **`ray/`**: Initial prototyping scripts for custom table widgets, ttkbootstrap notebook layouts, and UI sandbox tests.

> [!NOTE]
> None of the files in this directory are part of the active `shusha` runtime package or test suite.
