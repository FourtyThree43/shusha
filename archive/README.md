# Shusha Archive

This directory contains legacy experimental scripts, early GUI sandboxes, design prototypes, and historical modernization plans preserved for development reference.

---

## Directory Contents

- **[`drafts/`](file:///home/BillGates/code/shusha/archive/drafts/README.md)**: Early UI iterations, Tkinter window experiments, and exploratory scripts originally located in `src/shusha/_drafts/`.
- **[`ray/`](file:///home/BillGates/code/shusha/archive/ray/README.md)**: Initial prototyping scripts for custom table widgets, ttkbootstrap notebook layouts, and UI sandbox tests.
- **`Shusha Modernization Plan.md`**: Initial project analysis and architectural roadmap.

---

## Deprecation & Retention Policy

- **No Active Dependencies**: None of the files in this directory are part of the active `shusha` runtime package, build system, or test suite.
- **Cleanup Rule**: Build artifacts (`__pycache__`), backup files (`*.bak`), temporary databases (`*.db`), and duplicate annotated files should not be stored in this directory.
